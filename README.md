# BetterTouchpad

> 让 Android 触控板像鼠标一样好用

---

## 背景

随着越来越多搭载触控板的 Android 设备（平板键盘套装、外接键盘等）出现，
触控板的使用体验问题也逐渐暴露出来。

Android 生态中，触控板的处理方式高度碎片化：

- 不同厂商对触控板的驱动和事件上报方式各不相同
- 触控板的输入链路与鼠标不同，系统底层对其处理方式存在差异，这导致在**串流软件**（如 Moonlight）、**游戏软件**等对输入设备有严格要求的应用中，触控板往往**无法正常使用**或行为异常，使用体验**远远不及**鼠标
- 系统手势支持参差不齐，部分设备缺少多指手势支持

**BetterTouchpad** 正是为解决上述问题而生。

---

## 简介

BetterTouchpad 是一个运行在 Android 设备上的 **Root 级 Native 守护进程**，附带 Android 配置界面（APK）。

- **核心**：由 Native C 守护进程承担，直接在系统底层读取触控板原始事件、识别手势、并通过 uinput 注入标准鼠标事件，使触控板的行为更接近真实鼠标，以在**串流软件**（如 Moonlight）、**游戏软件**中拥有更好的表现，同时提供完整的系统级多指手势支持。
- **配置界面**：Android APK 负责参数配置与守护进程的启动 / 停止
- 守护进程由 APK 通过 Root Shell 拉起，**独立于 Android 应用框架运行**

---

## 工作原理

1. **事件拦截**：应用通过 Root 权限直接读取触控板对应的 `/dev/input/eventX` 设备节点，获取原始触摸事件（支持可选的 `EVIOCGRAB` 独占模式，防止系统其他进程同时读取）
2. **手势识别**：对原始触摸数据进行多指手势识别，判断单指/双指/三指的动作类型
3. **事件转换与注入**：
   - 使用 **uinput**（Linux 内核虚拟输入设备接口）创建一个虚拟鼠标设备，将识别到的手势转换为标准鼠标移动、点击、滚轮等事件注入系统
   - 多指手势通过模拟触摸注入系统，实现返回桌面、截图、分屏等操作
1. **自动设备检测**：通过 `getevent -p` 自动扫描触控板设备，获取设备路径和坐标范围，无需手动配置 (在小米平板上，触控板通常名为`Xiaomi Touch`。其他设备的触控板待适配)

## 功能

### 支持的手势

| 手势          | 行为          | 备注                |
|-------------|-------------|-------------------|
| 单指划动        | 移动鼠标光标      |                   |
| 单指单击        | 鼠标左键单击      |                   |
| 按下触控板（物理按压） | 鼠标左键单击      |                   |
| 轻触两下以拖移     | 双击后拖动（拖移模式） |                   |
| 双指单击        | 鼠标右键单击      |                   |
| 双指划动        | 鼠标滚轮滚动      | 支持自然滚动            |
| 双指捏合        | 真实两点触摸缩放    |    |
| 双指边缘内划      | 返回上一级       | 通过触摸注入实现          |
| 双指顶部下滑      | 通知中心 / 控制中心 | 左侧触发通知中心，右侧触发控制中心 |
| 三指单击        | 鼠标中键单击      |                   |
| 三指系统级手势     | 注入触摸        | 支持两种方案            |

## 设置可进行高度自定义

### 功能开关

- 单指划动 / 单指单击 / 物理按键单击
- 轻触两下以拖移
- 双指单击 / 双指滚动 / 自然滚动
- 双指捏合缩放
- 双指边缘内划返回
- 双指顶部下滑（通知中心 / 控制中心）
- 三指系统级手势
- 三指单击（鼠标中键）
- 三指手势实现方案（澎湃OS专用 / 通用方案）

### 灵敏度设置

| 参数               | 说明                           |
| ------------------ | ------------------------------ |
| 光标灵敏度         | 控制鼠标光标移动速度           |
| 滚轮灵敏度         | 控制双指滚动速度               |
| 双指捏合手势缩放灵敏度 | 影响捏合缩放响应速度       |
| 双指捏合手势判定阈值 (px) | 两指间距变化下限         |
| 三指手势触摸注入灵敏度 | 影响三指手势的注入速度     |

### 双指手势触发区域

| 参数                   | 说明                             |
| ---------------------- | -------------------------------- |
| 边缘手势触发区域宽度   | 边缘内划的触发区域占 X 轴的比例  |
| 顶部手势触发区域宽度   | 顶部下滑的触发区域占 X 轴的比例  |
| 顶部手势触发区域高度   | 顶部下滑的触发区域占 Y 轴的比例  |

### 双击拖移

| 参数           | 说明                             |
| -------------- | -------------------------------- |
| 双击拖移间隔时间 | 两次点击间隔不超过此值时触发（ms） |

### 触摸注入方向校正

| 参数     | 说明           |
| -------- | -------------- |
| XY 轴对调 | 交换横纵方向   |
| 反转 X 轴 | 水平方向取反   |
| 反转 Y 轴 | 垂直方向取反（默认开启） |

> 默认开启 XY 轴对调和反转 Y 轴，以适配小米设备。如手势方向异常，可在此调整。

### 兼容性设置

| 参数                | 说明                   | 默认 |
| ------------------- | ---------------------- | ---- |
| 独占设备 (EVIOCGRAB) | 独占触控板输入事件     | 开启 |
| 自动匹配触控板设备路径和坐标值范围 | 启动时自动扫描并获取设备路径及坐标最大值 | 开启 |

当**关闭自动匹配**时，可手动指定：
- 设备路径，如 `/dev/input/event5`
- X 轴坐标最大值，如 `2879`
- Y 轴坐标最大值，如 `1799`
